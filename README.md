# Esha & Sadath — Nikah Invitation

A responsive, single-page invitation with a tap-to-open maroon-and-gold cover, Arabic Bismillah, a two-panel opening transition, animated reveal, event countdown, a Google Maps button, calendar link, pastel guest palette, and music from the supplied MOV.

## Add your song

The attached MOV's audio was extracted to `assets/nikah-music.mp3`. Visitors tap the cover to open the invitation and start playback; the music button then pauses or resumes it. Browsers require a tap before a page can start audio.

## Preview

Open `index.html` in a browser. For a public share link, upload the folder to a static host such as GitHub Pages or Netlify.
